# Beyond Wings Holidays — Website

Single-page website for **Beyond Wings Holidays**: flight tickets, holiday packages, visa assistance and **Sannidhi**, the premium spiritual journeys program through Kerala.

## Structure

```
index.html            page markup (SEO meta, Open Graph, TravelAgency structured data)
assets/css/style.css  all styles (responsive via container queries)
assets/js/main.js     interactions: booking tabs, plan picker, filters, steps, enquiry form, hero animation
assets/img/           logo files and destination photos
```

No build step or dependencies — open `index.html` or host the folder on any static host (GitHub Pages, Netlify, Vercel).
